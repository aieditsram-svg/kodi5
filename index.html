Install in Kodi

Download repository.telugulive.zip

  1. Settings > System > Add-ons > turn on Unknown sources.
  2. Add-ons > Install from zip file. Either pick the downloaded repository.telugulive.zip from your device, or add a source first: Settings > File manager > Add source > enter
  3. Install from repository > Telugu Live Repository > Video add-ons > Telugu Live > Install.
  4. About 20 seconds after Kodi starts, answer Yes to "Load all channels into Kodi's TV section". Every channel then appears under TV, grouped by language.

Kodi on a TV box or phone: download the zip on that device, or copy it there with a USB drive. Kodi reads it from Downloads.
